# Nomi Video Downloader

A free and simple website for opening and previewing YouTube videos.

## Features
- Simple and user-friendly design
- Paste a YouTube video link
- Preview supported YouTube videos
- Free to use

## How to Use
1. Open the website.
2. Paste a YouTube video URL.
3. Click the preview button to view the video.

## Important Note
This website does not download or extract YouTube video files. Video playback depends on YouTube's embedding permissions and video availability.
